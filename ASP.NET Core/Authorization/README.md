# Authorization
- is the process that determines what a user is able to do

 For example, an administrative user is allowed to create a document library, add documents, edit documents, and delete them. A nonadministrative user working with the library is only authorized to read the documents.

### Types
- Role-based
- Claim-based
- Policy-based
