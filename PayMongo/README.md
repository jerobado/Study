# PayMongo

## Core workflow

1. Create a Payment Intent (server-side)

2. Create a Payment Method (client-side)

3. Attach the Payment Method to the Payment Intent (client-side)

4. Check status of the response if succeed or not and redirect back to your success page

5. Verify payment via webhook from PayMongo (server-side)
